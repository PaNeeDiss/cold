# 算得清 · Resale Ledger

一个适合球鞋、潮牌、相机、二手转卖的小型商品库存与利润系统。简体中文界面，以 USD 记账，不需要数据库或第三方 npm 依赖。

## 快速开始

下载仓库 ZIP、解压后双击 `index.html` 即可在浏览器运行。建议用 Chrome 或 Edge。

也可以使用 Node.js 18+：

```bash
npm start
# 打开 http://localhost:4173
npm test
```

## 已实现（v1.0 初始版）

- 新建商品、SKU、分类与低库存阈值
- 多批次采购入库（含该批次总运费）
- 记录销售数量、单价、总手续费、总发货运费和渠道
- FIFO（先进先出）逐件成本核算，采购运费分摊到件
- 商品库存、最近销售、销售收入、已实现利润与 SKU 利润表
- 删除记录，防止删除进货交易后造成库存负数
- 演示账本、JSON 导入/导出、交易 CSV 导出
- 本地浏览器 `localStorage` 保存

利润 = 销售收入 - 已售商品 FIFO 进货成本（含采购运费）- 手续费 - 发货运费。

**注意：** 目前未包括税费、广告费、仓储费、退款和人工等项目；这里的“利润”仅指上述项目核算后的已实现利润。

## 限制

- 数据**只存在当前浏览器**，GitHub 不会自动保存你的交易数据。定期导出 JSON 备份；请勿向公开仓库提交真实交易记录。
- 不支持登录、多设备同步、退货、SKU 修改、商品图片或支付接口。
- FIFO 以交易**录入先后顺序**计算，而不是日期排序；补录历史交易时尤其要注意。
- 当前系统是基础 MVP，建议先使用演示数据核验流程后再正式记账。

## 文件

- `index.html` - 页面结构
- `src/logic.js` - 纯 JavaScript FIFO 计算核心
- `src/app.js` - 表单和本地数据操作
- `src/style.css` - 响应式样式
- `tests/logic.test.js` - 核心计算单元测试
- `server.js` - 仅监听本机 127.0.0.1 的静态文件服务
