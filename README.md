# 算得清 · Resale Ledger

一个**无需后端、无需注册**的轻量进销存 + 转卖净利润计算系统（中文界面，所有金额为 USD）。适合球鞋、潮牌、相机、二手商品、小规模代购等生意。

## 直接开始

**最简单：** 下载整个项目，双击打开 `index.html` 即可使用（支持 Chrome / Edge / Safari 等现代浏览器）。

**开发方式：** 安装 Node.js 18+ 后，在项目文件夹中运行：

```bash
npm start
```

打开 `http://localhost:4173`。该服务器只绑定 `127.0.0.1`，不会公开到外网。

**运行自动测试：**

```bash
npm test
```

项目没有任何第三方 npm 依赖。

## 已实现（MVP v1.0）

- 商品管理：名称、SKU、分类、低库存提醒
- 采购入库：数量、单件进货成本、该笔进货的**总**运费
- 销售记录：数量、单件售价、该笔销售的**总**平台手续费和发货运费、渠道、交易日期、备注
- FIFO（先进先出）核算每笔销售成本；每个采购批次的额外运费按商品件数分摊，最小单位为美分
- 总览：累计收入、净利润、剩余库存件数、剩余库存成本、近 6 个月利润趋势
- 利润分析：各 SKU 利润、销售渠道金额、利润率
- 删除交易（如果删除采购会造成历史超卖，则拒绝删除）、删除从未发生过交易的商品
- 数据保存在本机浏览器 `localStorage`；JSON 导入 / 导出完整账本；CSV 导出交易流水
- 明确标记演示数据，只有账本为空时才能加载

### 利润计算

```text
销售净收益 = 销售数量 × 单件成交价格
           − 对应已售件数的 FIFO 采购成本（含分摊的采购运费）
           − 此订单的平台手续费
           − 此订单的发货运费
```

**例：** 先入库 2 件，每件 $100，整笔进货运费 $2；再入库 2 件，每件 $140。卖出 3 件，每件售价 $200，平台手续费 $12，发货运费 $8：

- 销售额：$600
- FIFO 销售成本：$342（$202 + $140）
- 净收益：**$238**
- 余货：1 件；余货进货成本：$140

> **范围说明：** 当前净收益未扣除税费、广告、仓储、包装、退款、汇兑成本、人员薪资等其他费用；不等于企业会计口径的税后净利润。

## 数据安全 / 局限

1. 当前是**单机离线工具**：浏览器清除站点数据、无痕浏览、换电脑均可能造成数据丢失。请经常点击“导出备份”。如果用 `localhost` 和直接打开 HTML，两者各自保存独立数据。
2. **不包含账号登录、云同步、支付收款或平台真实订单接口**。可通过导入 / 导出 JSON 手动迁移数据。
3. 各笔流水按**录入顺序**消耗 FIFO 批次，交易日期仅用于展示、筛选和月度图表；若事后补录历史交易，可能要调整录入顺序才能反映真实成本。
4. 销售为完整订单，不包含部分退款 / 换货 / 退货功能。暂不支持跨币种、成本调整、库存盘亏和从已有库存直接建账。
5. 所有金额限美元、最多两位小数；数量须为整数。通过分作为内部计量单位，避免常见的浮点货币误差。
6. 将仓库发布到公开网站前，应留意浏览器本地存储对多设备、隐私和数据备份的限制。
