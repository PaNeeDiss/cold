# 算得清 · 我的生意账本

这是一个**中文离线商品记账本**，适合个人倒卖 Chiikawa、潮牌、相机、球鞋等商品。无需登录、无需付费服务器，美元记账。

## 你可以记什么？

- **添加商品：** 第一次买某款商品，先创建名称和商品编号。
- **记进货：** 输入买了几件、每件成本及整批运费，自动增加库存。
- **记销售：** 输入卖了几件、每件售价、手续费及发货运费，自动扣库存并算利润。
- **记支出：** 包装、广告、交通等单独的经营开销。
- **看首页：** 全部进货投入、销售收款、已实现利润、剩余库存成本、现金回收差额。

> 注意：进货或销售里**已经填写过的运费，不要再重复记成额外支出**。

## 首页两个容易混淆的数字

**现金回收差额** = 全部销售收入 − 全部进货成本（含采购运费）− 销售手续费与发货运费 − 单独登记的其他支出。

**经营已实现利润** = 全部销售收入 − **已售出商品**的 FIFO 成本 − 销售手续费与发货运费 − 单独登记的其他支出。

前者回答「现在收到的销售款，扣掉已录入的投入还有多少差额？」；后者回答「已经卖出去的货账面赚了多少？」。这里假定所有进货费用已付、销售金额已收到，未考虑欠款与退款。

例如：买 39 件，每件 $4.81，花 $187.59；卖出 14 件，每件 $15，收入 $210。若没有其他费用，则现金回收差额为 **+$22.41**，已实现利润为 **$142.66**，还有 25 件商品、库存成本 $120.25。

## 如何打开

1. 在 GitHub 项目页点击 **Code → Download ZIP**。
2. 解压缩，确保 `index.html` 和 `src` 文件夹留在**同一个文件夹**。
3. 双击 `index.html`，推荐 Chrome 或 Edge。
4. 想以后像软件一样从桌面打开？在 `index.html` 上点击右键 → 显示更多选项 → 发送到 → 桌面快捷方式。

请不要单独把 `index.html` 拖到桌面。应当建立快捷方式，避免丢失样式文件路径。

### 更新版本：一定先备份旧账本

使用旧版时先点 **下载账本备份 / 导出 JSON**，保存好备份文件；再下载最新版，把新版 `index.html` 和 `src` 文件夹复制到**原来的项目文件夹**并替换同名文件，保留原来的桌面快捷方式。尽量维持同一个文件路径和浏览器，否则 localStorage 里的账本可能不可见。如果新版打开后看不到历史记录，点击 **导入旧账本** 并选刚导出的 JSON。

> GitHub 只保存程序源代码，**不会自动保存你的私人流水**。浏览器清理数据、路径变更或换电脑，都可能使当地记账记录不可用。建议每次大改版前和每周定期导出 JSON。

## 开发与测试

需要 Node.js 18+：

```bash
npm start
# http://localhost:4173

npm test
```

项目不用安装 npm 依赖。仓库已配置 GitHub Actions 测试工作流。

## 重要限制

- 目前是**本地单机**账本，不包含跨设备同步、账号登录、支付、退货/退款或库存盘点。
- FIFO 按**录入先后顺序**消耗进货批次，不以填写的交易日期来重排库存成本。补录很久以前的交易时，请留意顺序。
- 各商品的销售利润不含独立的其他支出，但首页「经营已实现利润」会扣这些额外费用。
- 暂不包含税费、人工、银行收付时间差、货款欠款、跨币种换算等未录入项目；它不等同于正式的税务或财务报表。
- 不要把真实交易 JSON 备份上传到公开 GitHub 仓库。
